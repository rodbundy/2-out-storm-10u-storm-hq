# Apps Script install order

1. Code.gs
2. Admin.html
3. FamilyPortal.html
4. LineupBuilder.html
5. StormStyles.html
6. appsscript.json

After all six are installed:

1. Run `initializeStormHQ` once.
2. Refresh the Google Sheet.
3. Storm HQ > Set Coach Password.
4. Storm HQ > Create / Repair Google Forms.
5. Storm HQ > Install Form Trigger.
6. Deploy as Web App.
