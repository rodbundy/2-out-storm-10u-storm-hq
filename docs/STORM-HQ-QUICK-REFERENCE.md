# Storm HQ Quick Reference

## Add a practice or game
Coach Control Center > **Schedule & Games** > **Add Event**. Use a real date and plain text time such as `6:00 PM`.

## Post information to the team
Coach Control Center > **Team Messages** > **Post Message**. Choose Public, Family, or Both.

## Fix a player photo
Coach Control Center > **Players & Photos** > **Edit Player**. Adjust Card X/Y/Zoom and Profile X/Y/Zoom while watching the live previews.

## Add tryout information
Coach Control Center > **Tryout Center** > **Add Tryout**.

## Post homework
Coach Control Center > **Storm Homework** > **New Week**. Add drills and questions, then set the week to ACTIVE.

## Check homework totals
Coach Control Center > **Team Reports**.

## Assign girls to an event
Coach Control Center > **Event Groups** > choose event > check players > Save Event Group.

## Build and print a lineup
Coach Control Center > **Game Day Builder** > choose game. Build Starting Order, Adjustment 1, Adjustment 2, and inning defense. Use **Print / Save PDF** or **Export CSV**.

## Approve an Accepted Player form
Coach Control Center > **Pending Approvals** > Review & Approve.

## Reset the Coach password
Google Sheet > **Storm HQ > Set Coach Password**.

## Website says Connection Needed
Open GitHub `assets/js/config.js` and verify the deployed Apps Script URL ending in `/exec` is in `apiUrl`.

## Apps Script code changed
Apps Script > **Deploy > Manage deployments > Edit > New version > Deploy**.

## Data changed only
Do not redeploy. Refresh the site.
