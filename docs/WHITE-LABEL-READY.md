# White-label / Future Product Notes

Storm HQ is intentionally separating the team identity from the core engine.

The following are editable settings rather than hard-coded product assumptions:

- team name and short name
- age group
- tagline
- logo URL
- primary / secondary / accent / dark colors
- coach name
- phone and email
- home field
- website domain
- Google Form links
- GameChanger and social links
- homepage hero copy

This makes the architecture suitable for a future multi-team or sellable version. Before commercial sale, add proper user accounts, per-customer data isolation, terms/privacy language, billing, onboarding, support, and a more scalable backend than a single Google Sheet.
