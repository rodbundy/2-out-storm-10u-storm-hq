# Google Forms Workflow

Storm HQ can create four forms for you:

1. Player Interest
2. Accepted Player Information
3. Private Parent Message
4. Picture of the Week Submission

Use Google Sheet > **Storm HQ > Create / Repair Google Forms**.

The form URLs are stored in **Form Registry** and copied into **Website Settings**.

## Accepted Player workflow

Accepted Player Form -> Google response tab -> installed form trigger -> Pending Players -> Coach Control Center review -> Approve -> Website Players -> Parent Code generated.

Nothing from the Accepted Player Form becomes public without coach approval.

## Existing form instead of new form

If you want to keep an existing Accepted Player form:

1. Link its responses to the Storm HQ Google Sheet.
2. Note the exact response tab name.
3. Google Sheet > **Storm HQ > Set Accepted Player Response Tab**.
4. Google Sheet > **Storm HQ > Install Form Trigger**.
5. In Coach Control Center > Pending Approvals, use **Import Existing Form Responses** for older submissions.
