Coach Control Center

Daily Updates

Open the Coach Control Center from the site footer. Use Schedule for practices/games, Team Messages for announcements, and Dashboard for quick status checks.

Players & Photos

Open Players → Edit. Upload the original photo, then use Card X/Y/Zoom and Profile X/Y/Zoom while watching the live previews. Save when the face and framing look right.

Schedule & Event Details

Create an event once. It feeds the Tracker, Next Impact countdown, event details, availability, event roster, and Game Day Builder.

Tryouts

Create tryouts in the Tryout Manager. Set status, positions wanted, registration link, arrival time, and what to bring. Active tryouts automatically appear publicly.

Homework

Create a week, add drills and questions, then publish it. Parents use their player code to confirm work and submit answers. Review completion in Reports.

Game Day Builder

Select a game, choose attending players, create Starting Order plus two alternate plans, assign positions by inning, save, then print/save PDF/export CSV.

Forms

Use Branding & Forms → Create/Repair Google Forms during first setup. Accepted Player submissions enter Pending Players for coach approval before going public.

Troubleshooting

If the site says “Connection needed,” check assets/js/config.js for the deployed Apps Script /exec URL. If new Apps Script code was installed, deploy a New version. Times should be entered as plain times such as 6:00 PM.

For the full step-by-step setup and troubleshooting manual, use the Owner's Manual included with the master package.
